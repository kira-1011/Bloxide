# Sprite art

`robot.png` is the walking pose from the Robot in Kenney's **Toon Characters**
(`PNG/Poses HD/character_robot_walk4.png`) — <https://kenney.nl/assets/toon-characters>,
downloaded 2026-09-20.

Licensed **CC0 1.0** (public domain dedication): no attribution required, commercial use
allowed. <http://creativecommons.org/publicdomain/zero/1.0/>

CC0 asks for nothing, but the next person to touch this folder should not have to guess
where the art came from or whether it can ship.

A robot rather than one of the pack's people: a child picks up whichever sprite is on
screen as "them", and a robot does not ask them to see themselves in a particular face.
The walking pose over the idle one because its stride is asymmetric, so the left-right
flip that shows which way the sprite faces is actually visible.
